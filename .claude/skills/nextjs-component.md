# Next.js Component Creation Skill

## Purpose
This skill helps create Next.js components following best practices and patterns.

## Usage
When asked to create Next.js components, use this skill to:
- Follow Next.js 13+ App Router conventions
- Include proper TypeScript typing
- Use Tailwind CSS for styling (if project uses it)
- Follow accessibility best practices
- Include proper error boundaries where needed

## Guidelines
1. Always use functional components with TypeScript interfaces
2. Follow the file-based routing structure of Next.js App Router
3. Use client components ("use client") when needed for interactivity
4. Use server components by default for better performance
5. Include proper prop validation
6. Follow Next.js Image, Link, and other component best practices
