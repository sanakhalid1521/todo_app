# Next.js General Best Practices Skill

## Purpose
This skill helps implement Next.js applications following general best practices.

## Usage
When working with Next.js projects, use this skill to:
- Optimize performance with code splitting
- Implement proper data fetching strategies
- Use appropriate React patterns
- Follow Next.js specific conventions
- Handle deployment configurations

## Guidelines
1. Use static generation (generateStaticParams) for mostly-static content
2. Use server-side rendering (SSR) for frequently updated content
3. Use client-side rendering (CSR) for interactive components
4. Implement proper caching strategies
5. Optimize images using Next.js Image component
6. Handle fonts efficiently using @next/font
7. Implement proper metadata for SEO
8. Use middleware for request processing when needed
9. Follow security best practices
