# Next.js Routing Skill

## Purpose
This skill helps implement Next.js routing following App Router conventions.

## Usage
When asked to implement routing or navigation in Next.js, use this skill to:
- Create proper route structures in the app directory
- Implement dynamic routes using bracket notation [param]
- Use the new Next.js 13+ file convention patterns
- Handle route groups and parallel routes when needed
- Implement proper navigation with the new useSearchParams hook

## Guidelines
1. Use the app directory structure for routing
2. Leverage route groups (e.g., (auth)) for organizing routes
3. Implement loading states with loading.tsx
4. Handle errors with error.tsx and global-error.tsx
5. Use not-found.tsx for 404 pages
6. Follow SEO best practices with metadata
