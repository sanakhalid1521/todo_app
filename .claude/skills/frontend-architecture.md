# Frontend Architecture Skill

## Purpose
This skill helps implement frontend features following Next.js best practices and the existing architecture.

## Usage
When asked to create or modify frontend components, use this skill to:
- Follow Next.js App Router conventions
- Implement proper client/server component patterns
- Use appropriate state management strategies
- Follow the existing UI/UX patterns
- Maintain responsive design principles
- Implement proper data fetching strategies

## Guidelines
1. Use Next.js App Router structure in /frontend/app/
2. Implement proper use client directives where needed
3. Follow existing component architecture patterns
4. Use appropriate context providers for state management
5. Implement proper TypeScript interfaces for props
6. Follow the existing Tailwind CSS patterns with glass morphism design
7. Use proper data fetching patterns (client vs server components)
8. Implement proper error boundaries and loading states
9. Follow accessibility best practices
10. Maintain responsive design across all components
11. Use existing UI component patterns for consistency
12. Implement proper form validation and error handling
13. Follow existing API integration patterns in lib/ directory
